# ケータリング現場終了後アンケート 質問設計書

ケータリング案件の現場終了後、その日のうちに担当者がGoogleフォームで回答する想定の質問項目設計書です。
Googleフォーム作成時にこの通りセクション・質問を作成してください。質問タイトルの表記は `gas/Config.gs` の
列名マッピングと対応させているため、変更する場合は両方を合わせて修正してください。

## セクション1: 案件基本情報

| No | 質問 | 形式 | 必須 | 選択肢/備考 |
|----|------|------|------|------|
| 1 | 案件名 | 記述式(短文) | 必須 | 案件管理シートの「案件名」と完全一致させる(突合キー) |
| 2 | 実施日 | 日付 | 必須 | |
| 3 | 会場 | 記述式(短文) | 任意 | |
| 4 | 回答者(あなたの名前) | 記述式(短文) | 必須 | |
| 5 | 現場担当スタッフ | 記述式(段落) | 任意 | 複数名の場合はカンマ区切り |

## セクション2: 現場運営の振り返り

| No | 質問 | 形式 | 必須 | 選択肢/備考 |
|----|------|------|------|------|
| 6 | 準備・搬入はスムーズだったか | 均等目盛(1〜5) | 必須 | 1=大変だった 5=非常にスムーズ |
| 7 | 良かった点 | 記述式(段落) | 任意 | |
| 8 | 改善が必要な点・気づき | 記述式(段落) | 任意 | |
| 9 | 現場で発生したトラブル・ハプニング | 記述式(段落) | 任意 | なければ空欄でよい |
| 10 | 備品・食材の過不足 | ラジオボタン | 必須 | 過剰 / 適正 / 不足 |
| 11 | 過不足の詳細 | 記述式(段落) | 任意 | 10で「過剰」「不足」を選んだ場合に記入 |

## セクション3: 数値実績

| No | 質問 | 形式 | 必須 | 選択肢/備考 |
|----|------|------|------|------|
| 12 | 実際の来場者数/喫食数 | 記述式(短文・数値) | 任意 | |
| 13 | 食材ロス量の目安 | ラジオボタン | 任意 | なし / 少量 / 中程度 / 多い |
| 14 | 追加発注・追加対応の有無 | ラジオボタン | 任意 | あり / なし |
| 15 | 追加発注・追加対応の内容 | 記述式(段落) | 任意 | 14で「あり」の場合に記入 |

## セクション4: 顧客・クライアント対応

| No | 質問 | 形式 | 必須 | 選択肢/備考 |
|----|------|------|------|------|
| 16 | クライアントの反応 | 均等目盛(1〜5) | 必須 | 1=不満そうだった 5=非常に満足そうだった |
| 17 | クライアントからの追加要望・コメント | 記述式(段落) | 任意 | |
| 18 | 次回受注の見込み | ラジオボタン | 任意 | 高い / 普通 / 低い / 未定 |
| 19 | クレーム・要対応事項の有無 | ラジオボタン | 必須 | あり(要対応) / なし |
| 20 | クレーム・要対応事項の内容 | 記述式(段落) | 任意 | 19で「あり」の場合に記入。ここが埋まっていると自動メール通知されます |

## 運用ルール

- 質問19「クレーム・要対応事項の有無」で「あり(要対応)」が選択されると、`gas/Code.gs` が
  設定済みの担当者宛てに自動でメール通知します。通知が不要な軽微な連絡のみの場合は「なし」を選び、
  質問9(トラブル・ハプニング)に記載してください。
- 質問1「案件名」は案件管理スプレッドシートの「案件名」列と完全一致させてください。一致しない場合、
  自動転記がスキップされ、ログシートに未突合として記録されます。
- 質問形式・順序を変更した場合は、GAS側の列名参照(`gas/Config.gs` の `FORM_COLUMNS`)も合わせて更新してください。
