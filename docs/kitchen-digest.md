# キッチン指示書メール(毎朝自動送信)

デリプロの「キッチン指示書(注文別:メイン)」PDFを読み取り、今日から7日先までの注文を
日別一覧と大型案件(50名以上)一覧に整理して、PDFを添付して毎朝7時台に `buffet@lit-house.jp` へ送ります。

## フェーズ1(現在): PDFを所定フォルダに置く運用

デリプロからの自動ダウンロードは、ログイン画面の仕様確認が済むまでの間、手作業1分で代替します。

1. 毎朝7時までに、デリプロ「集配管理」で期間を 今日〜7日後、注文状態を空欄にして「キッチン指示書(注文別:メイン)」をダウンロード
2. ダウンロードした `kitchen_YYMMDDhhmm.pdf` をドライブの受け取りフォルダに保存
3. 7時台にGASが最新のPDFを読み取ってメール送信。20時間以内のPDFがなければ「未保存」の警告メールを送ります

## フェーズ2(予定): デリプロから自動ダウンロード

`getKitchenPdf_()` を、デリプロにログインしてPDFを取得する処理に差し替えます。
集配一覧の画面から「保留」の注文番号も取得し、メールに保留・確定の区別を付けます。
ID・パスワードはコードに書かず、スクリプトプロパティに保存します。

## メールの内容

- 件名: `【キッチン指示書】10/11(日)〜10/18(日) 61件・大型10件`
- 合計件数・人数、大型案件の件数・人数
- 大型案件: 残り日数・時間・No.・人数・お客様・プラン・お届け先
- 日別一覧: 日ごとの件数・人数と注文明細(大型は赤)
- 添付: 元のキッチン指示書PDF

## 人数の推定ルール

PDFに人数欄がないため、次の最大値を人数とみなします。

- プラン欄 `【プラン × 数量】` の数量(諸経費・単品・ドリンク単品・LIVE・ケーキは除外)
- 料理明細の数量(複数プランの合計人数分の料理が並ぶため)
- 大皿 `(20人前) 1` は 人前×数量

## セットアップ

1. ドライブに受け取りフォルダを作り、URLの `folders/` の後ろのIDを `Config.gs` の `INBOX_FOLDER_ID` に設定
2. https://script.google.com で新しいプロジェクトを作成し、`gas/kitchen-digest/` の4ファイルを貼り付け
3. 「サービス」で Drive API(v3)を追加(`appsscript.json` を貼っていれば追加済み)
4. PDFをフォルダに置いて `testKitchenDigestToAdmin` を実行し、権限を承認して内容を確認
5. `setupKitchenTrigger` を1回だけ実行

テスト: `node tests/kitchen-parser.test.js`(テスト用データは架空)
