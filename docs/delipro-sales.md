# デリプロ売上集計(PLの売上欄の自動化)

PLのスプレッドシートで毎回デリプロから手入力している「売上」の欄(注文区分×支払方法×税率)を、
GASでデリプロから自動集計するための仕組みです。
キッチン指示書メール(`gas/kitchen-digest/`)とは別のApps Scriptプロジェクトで動かし、
片方の変更やエラーがもう片方に影響しないようにしています。

## 現在の段階

1. 調査: デリプロのダウンロード(CSV)にどの列があるか確認する ← いまここ
2. 集計: 注文区分×支払方法×税率で合計を出す
3. 出力: PLのファイルに別シート「デリプロ売上集計」を作って自動記入

## セットアップ(初回のみ)

1. https://script.google.com で新しいプロジェクトを作成(名前の例: デリプロ売上集計)
2. `dist/delipro-sales.gs` の中身を「コード.gs」に丸ごと貼り付けて保存
3. 「プロジェクトの設定」→「スクリプト プロパティ」に次を登録(コードやGitHubには書かない)
   - `DELIPRO_CONTRACT_ID` / `DELIPRO_STAFF_ID` / `DELIPRO_PASSWORD`(キッチン指示書メールと同じ値)

## 調査用の関数

- `probeDeliproPages`: 集配管理の検索前の画面と、今日配達分の検索結果の画面(HTML)を同じフォルダに保存します。
  CSVに無い注文区分・事業所・税率の取り方を調べるために使います。
- `probeDeliproCsv`: 今月1日〜今日に配達した確定注文について、集配管理の3種類のダウンロード
  (ダウンロード / 明細DL / 発注書DL)をマイドライブの「delipro_probe」フォルダに保存します。
  メールは送らず、デリプロのデータも変更しません。

## ファイル構成

`gas/delipro-sales/` の `Config.gs`・`DeliListParser.gs`・`DeliproClient.gs`・`CsvProbe.gs` を
1つにまとめたものが `dist/delipro-sales.gs` です。デリプロへのログインと検索の部分は
キッチン指示書メールと同じ内容です。
