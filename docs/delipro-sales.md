# デリプロ売上集計(PLの売上欄の自動化)

PLのスプレッドシートで毎回デリプロから手入力している「売上」の欄(注文区分×支払方法×税率)を、
GASでデリプロから自動集計するための仕組みです。
キッチン指示書メール(`gas/kitchen-digest/`)とは別のApps Scriptプロジェクトで動かし、
片方の変更やエラーがもう片方に影響しないようにしています。

## 現在の段階

1. 調査: デリプロのダウンロード(CSV)にどの列があるか確認する(済)
2. 集計: 注文区分×支払区分の税込金額を出す(済)
3. 税率(10%・8%・0%)の内訳: 「売上分析(期間)」(analyze_sale_time.php)から区分ごとに取る(済)
4. 毎朝の自動更新と締めの確認(済)
5. PLへの反映: PL転記用のシートとPLの手入力との照合 ← いまここ

## 集計のしかた

- `summarizeThisMonth`: 今月1日〜今日の配達分 / `summarizeLastMonth`: 前月分
- 対象: 配達日が期間内の注文。「確定＋保留」「確定のみ」「保留のみ」の3つの表を出す(取消・練習は除く)。計上月は配達日の月
- デリプロの「売上分析(注文)」で注文状態を空欄にした数字は「確定＋保留」、確定を選んだ数字は「確定のみ」と一致する(2026/10 大阪直販・請求書で確認)
- 金額: デリプロの「合計金額」(税込)
- 注文区分ごとに集配管理を検索して区分を決め、「ダウンロード」CSVの支払区分・合計金額を足す
- 区分を指定しない検索の件数を正とし、どの区分にも入らない注文は「区分なし」として黄色で表示する
- 税率別の金額は「売上分析(期間)」でお届け日・注文区分・注文状態(確定/保留)を指定して取る。10%・8%対象は税込。
  支払区分別の合計と一致しない行は「照合」の列が赤くなる
- すたフェス経由は「直販」で入力する運用のため、直販に含まれる
- 結果は専用のスプレッドシート「デリプロ売上集計」に月ごとのシート(例: 2026-10)で書き込む。
  初回実行時に自動で作り、スクリプトプロパティ `SALES_SHEET_ID` に保存する。PLのファイルには書き込まない

## セットアップ(初回のみ)

1. https://script.google.com で新しいプロジェクトを作成(名前の例: デリプロ売上集計)
2. `dist/delipro-sales.gs` の中身を「コード.gs」に丸ごと貼り付けて保存
3. 「プロジェクトの設定」→「スクリプト プロパティ」に次を登録(コードやGitHubには書かない)
   - `DELIPRO_CONTRACT_ID` / `DELIPRO_STAFF_ID` / `DELIPRO_PASSWORD`(キッチン指示書メールと同じ値)

## PLへの反映

- 集計のたびに、集計用スプレッドシートに PL と同じ名前のシート(`PL_Mr.BUFFET_関西` など)を作り、
  PLの売上欄と同じセル番地に「確定＋保留」の数字を書く(`PL_LAYOUT`)。PL側は同じ番地を IMPORTRANGE で参照する
- 10%・8%・0%対象は税込の対象額(PLの今の入れ方と同じ)。計(税抜)はデリプロが計算した税抜をそのまま置く
- PLに欄がない支払区分(例: 東京直販の「未定」)があれば、毎朝のメールで知らせる
- `comparePlMonth`: 前月(またはスクリプトプロパティ `COMPARE_MONTH` の月)をデリプロから集計し、
  PLの手入力の数字と並べた「PL照合_yyyy-MM」シートを作る。PLは読むだけ(スクリプトプロパティ `PL_SHEET_ID`)
- 注意: PLの「計(税抜)」の式は、税込の対象額に0.1・0.08を掛けて税を引いているため、税抜が小さく出る
  (正しくは 10/110・8/108)。2026年3〜9月の関西(直販・CS・ごちクル)で計 約68万円

## 毎朝の自動実行

- `setupSalesTrigger` を1回実行すると、毎朝6時台に `dailySalesJob` が動く(`TRIGGER_HOUR`)
- 今月分を毎朝更新する。月初5日間(`CLOSE_CHECK_DAYS`)は前月分も更新する
- 次の場合だけメールが届く(何もなければ届かない)。宛先はスクリプトプロパティ `NOTIFY_TO`(カンマ区切り)、
  未登録なら実行しているアカウント
  - 前月分に保留の注文が残っている(月初5日間)。注文番号・お客様・金額の一覧付き
  - 注文区分が未設定の注文がある
  - 支払区分別の合計と売上分析の合計が合わない
  - エラーで集計できなかった

## 調査用の関数

- `probeDeliproAnalysis`: 税率別の金額が出る「売上分析(期間)」(analyze_sale_time.php)とメインメニューの画面を同じフォルダに保存します。
- `probeDeliproPages`: 集配管理の検索前の画面と、今日配達分の検索結果の画面(HTML)を同じフォルダに保存します。
  CSVに無い注文区分・事業所・税率の取り方を調べるために使います。
- `probeDeliproCsv`: 今月1日〜今日に配達した確定注文について、集配管理の3種類のダウンロード
  (ダウンロード / 明細DL / 発注書DL)をマイドライブの「delipro_probe」フォルダに保存します。
  メールは送らず、デリプロのデータも変更しません。
