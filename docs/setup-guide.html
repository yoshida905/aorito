金庫管理の導入ガイド

「大阪GB｜現金出納帳」に、金庫の残高を3つに分けて計算する仕組みを入れる手順です。パソコンで、上から順に進めてください。所要時間はおよそ15分です。

作業する場所パソコン(スマホ不可)
必要なものフォームとシートの「編集者」権限
入力する数字数えた日時と 29968

注意 途中で分からなくなったら、その画面のスクリーンショットを送ってください。途中でやめても、スプレッドシートの記録は消えません。

はじめに: 編集できる権限があるか確認する

スプレッドシートを開いたとき、上の方に コメントのみ や 閲覧のみ と出ていたり、メニューの 拡張機能 が薄い灰色で押せなかったりする場合は、編集の権限がありません。このままでは先に進めません。

  1. 持ち主(オーナー)を確かめる メニューの ファイル → 詳細 を開くと「オーナー」の名前が出ます。
  2. オーナーに編集者にしてもらう オーナーの方に、次の2つをお願いします。
    • スプレッドシート: 右上の 共有 → 自分の名前の右の 閲覧者(コメント可) → 編集者 → 保存
    • フォーム: フォームの編集画面の右上の ︙ → 共同編集者を追加 → 自分のメールアドレスを追加
  3. オーナー本人が作業するのも一案 通知メールや毎週の自動処理は、初期設定をした人のアカウントで動きます。担当者が退職しても止まらないよう、会社で管理しているアカウント(オーナー)で初期設定するのが確実です。

A. 担当者をプルダウンにする(フォーム側)

  1. スプレッドシートを開く 「大阪GB｜現金出納帳」を開きます。
  2. フォームの編集画面を開く 上のメニューで ツール → フォームを管理 → フォームを編集 の順にクリックします。新しいタブでフォームの編集画面が開きます。
  3. 「担当者」の質問をクリックする 質問の枠が選ばれた状態(左端に色の線が出る)になります。
  4. 質問の種類を「プルダウン」に変える 質問の右上にある 記述式 と書かれた箱をクリックし、一覧から プルダウン を選びます。
    • 選択肢は「オプション 1」のままで大丈夫です。名前はあとで自動で入ります。
    • フォームは自動で保存されます。このタブは閉じてかまいません。

B. 仕組みを貼り付ける(スプレッドシート側)

  1. Apps Scriptを開く スプレッドシートに戻り、上のメニューで 拡張機能 → Apps Script をクリックします。新しいタブで、プログラムを書く画面が開きます。
  2. 最初からある文字を消す 左の「ファイル」の下にある コード.gs をクリックします。右側の広い白い部分をクリックし、Ctrl + A(Macは ⌘ + A)で全部選んで、Delete で消します。

    確認 消す前の中身が function myFunction() {} の3行だけでなければ、消さずに止めて連絡してください。別の仕組みが入っている可能性があります。

  3. このページのコードをコピーする 下のボタンを押すと、仕組み全体(594行)がコピーされます。
    コードの中身を見る(ボタンが効かないときは、ここを開いて全部選んでコピー)
  4. Apps Scriptに貼り付けて保存する Apps Scriptのタブに戻り、白い部分をクリックして Ctrl + V(Macは ⌘ + V)で貼り付けます。続けて Ctrl + S(Macは ⌘ + S)で保存します。
    • 上部の「コード.gs」の横に出ていた丸い印が消えれば保存できています。
  5. スプレッドシートを再読み込みする スプレッドシートのタブに戻り、F5(Macは ⌘ + R)を押します。10秒ほど待つと、上のメニューの ヘルプ の右に 金庫 が出てきます。

C. 初期設定を実行する

  1. 初期設定を選ぶ 金庫 → 初期設定(最初に1回だけ) をクリックします。
  2. 許可する(初回だけ) 「承認が必要です」と出たら、次の順に進みます。
    • 続行 を押し、自分のGoogleアカウントを選ぶ
    • 「このアプリはGoogleで確認されていません」と出たら、左下の 詳細 → (プロジェクト名)(安全ではないページ)に移動
    • 許可 を押す

    補足 「確認されていません」は、自社で作ったプログラムに必ず出る表示です。許可したあと画面が止まったら、もう一度 金庫 → 初期設定 を選んでください。

  3. 1つ目の質問: 金庫を数えた日時 9月27日に金庫を数えた時刻を、2026/09/27 15:00 の形で入力して OK。
    • 時刻が分からなければ、数えた時刻より少し前にしてください。
  4. 2つ目の質問: 数えた金庫金 29968 と入力して OK(カンマや「円」は不要です)。
  5. 完了メッセージを確認する 「初期設定が完了しました」と出たら OK。メッセージに「処理区分の選択肢を5つに変更しました」「担当者のプルダウンを11名にしました」と書かれていれば成功です。

D. うまくいったか確認する

  • 「現金残高」シートの一番上、「金庫にあるはずの合計」が 79,968 になっている
  • フォームを開くと、「処理区分」が5つの選択肢になっている
  • フォームの「担当者」で、迫田・大岡・吉田・山下・平山・藤川・渡邊・楠・山口・空野・花川 が選べる
  • 金庫 → 週次メールを今すぐ送る で、yoshida@lit-house.jp にメールが届く
