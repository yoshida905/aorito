# デリPRO 売上CSV自動取得スクリプト

デリPROの管理画面に自動ログインし、売上CSVをダウンロードして、
「大阪GB｜人時限界利益」フォーマットの `03_デリPRO_CSV` シートに自動反映するための一式です。

**社内PC（Windows/Mac問わず、常時起動できる1台）で動かす前提**で作っています。
このコードを書いたセッションはネットワーク制限によりデリPROのサイトへ接続できず、
実際のログイン画面の項目名（セレクタ）を直接確認できていません。
そのため、**最初に「操作の記録」という準備作業が必須**です。順番に進めてください。

---

## 全体の流れ

1. 準備：Python と Playwright をインストールする
2. 記録：実際にログイン〜CSVダウンロードまでを一度手動で行い、その操作をコードとして記録する
3. 組み込み：記録した操作を `export_delipro.py` に反映する
4. 保管：ID・パスワードを安全な場所に保管する
5. スケジュール登録：毎日決まった時刻に自動実行されるようにする
6. 動作確認：実際に自動実行させて、Excelに反映されるか確認する

---

## 1. 準備

社内PCに Python 3.10以上がインストールされていることを確認してください。
その上で、このフォルダで以下を実行します。

```bash
cd automation/delipro_export
python -m venv venv
venv\Scripts\activate        # Windowsの場合
# source venv/bin/activate   # Macの場合
pip install -r requirements.txt
playwright install chromium
```

---

## 2. 記録（もっとも重要な手順）

Playwrightには「実際にブラウザを操作すると、その操作をそのままPythonコードとして
書き出してくれる」機能（codegen）があります。これを使って、実際の画面の入力欄名を
調べる必要はなく、操作をそのまま記録させます。

以下を実行すると、ブラウザが立ち上がります。

```bash
playwright codegen https://asp.delipro.jp/dmanager/deli.php
```

ブラウザが開いたら、**普段統括の方が行っている操作をそのまま**行ってください。

1. 契約者ID・スタッフID・パスワードを入力欄に入力する
2. ログインボタンを押す
3. 売上明細（CSVダウンロードの元になる画面）に移動する
4. CSVダウンロードのボタンを押す

操作を行うと、別ウィンドウ（Playwright Inspector）にPythonコードがリアルタイムで
表示されます。ログイン〜ダウンロードが終わったら、そのウィンドウに表示されている
コード全体をコピーしてください。

コピーしたコードを `recorded_flow.py`（このフォルダに新規作成）として保存し、
私に共有してください。そこに書かれている「入力欄の名前」「ボタンの名前」を
`export_delipro.py` の該当箇所（`# TODO: codegenの記録結果に置き換える` とコメントが
入っている部分）に反映します。

---

## 3. 組み込み

`recorded_flow.py` の内容を教えていただければ、`export_delipro.py` 内の
以下の関数を実際のセレクタに書き換えます。現時点では仮の内容が入っています。

- `login()` … ログイン操作
- `open_sales_csv_page()` … 売上CSVがダウンロードできる画面への遷移
- `download_csv()` … ダウンロード操作

---

## 4. ID・パスワードの保管

`config.example.json` を `config.json` にコピーし、中身を実際の値に書き換えてください。

```bash
cp config.example.json config.json
```

`config.json` は `.gitignore` に登録済みのため、**Gitには一切記録されません**。
このファイルは第三者に見られないよう、社内PC上でアクセス権限を絞って保管してください
（他の社員がログインするアカウントから読めない場所に置く、など）。

このスクリプトを動かし終えたら、念のためデリPRO側でパスワードの再発行をおすすめします
（今回チャットに一度平文で貼っていただいているため）。

---

## 5. スケジュール登録（Windowsの場合）

タスクスケジューラで、毎朝決まった時刻（例：6:00）に以下を実行するよう登録します。

```
プログラム: C:\path\to\venv\Scripts\python.exe
引数:      C:\path\to\automation\delipro_export\export_delipro.py
開始（作業）フォルダ: C:\path\to\automation\delipro_export
```

「ユーザーがログオンしていなくても実行する」を選び、PCの電源が入っていれば
ログイン画面のままでも動くようにしておくことをおすすめします。

---

## 6. 動作確認

まずは手動で一度実行して、正しく動くか確認してください。

```bash
python export_delipro.py --headed
```

`--headed` を付けるとブラウザ画面が実際に表示されるので、
どこで失敗しているか目視で確認できます。問題なければ `--headed` を外した
通常実行（画面を表示しない headless 実行）で本番運用に入ります。

---

## うまくいかない場合によくある原因

- デリPRO側の画面デザインが変わり、記録したボタンの位置や名前が変わった
  → 2.の記録作業をやり直す
- ログインに失敗する（IDやパスワードの入力欄が正しく特定できていない）
  → `--headed` を付けて実行し、実際にどこで止まっているか確認する
- 2段階認証・reCAPTCHAなどが表示される
  → その場合は完全自動化ができません。表示されたら私に知らせてください。代替案を検討します
- ダウンロードしたCSVの文字コードが想定と異なりExcelに反映した際に文字化けする
  → `config.json` の `csv_encoding` を `"utf-8"` や `"shift_jis"` に変更して試す

---

## セキュリティ上の注意

- `config.json`・ダウンロードしたCSV・ログファイルは、いずれも顧客の個人情報
  （氏名・住所・電話番号）を含みます。共有フォルダなど複数人がアクセスできる場所には
  置かないでください。
- この自動化がデリPROの利用規約に違反しないか、必ず事前にデリPRO社へ確認してください。
  規約で自動アクセスが禁止されている場合、この仕組みは使用できません。
